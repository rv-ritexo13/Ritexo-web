LOGO PLACEHOLDER
================

Place the official Ritexo logo in this folder as:

    ritexo-logo.png

The site references it at:  /assets/ritexo-logo.png

Until the file exists, the header/footer show a branded "R" monogram
placeholder automatically (see src/components/Logo.jsx). Once you drop
ritexo-logo.png here and refresh, the real logo appears everywhere with
no code changes.

Recommended: transparent PNG or SVG, ~200px tall, wordmark on transparent
background. To use a different filename or SVG, update `brand.logo` in
src/data/websiteContent.js.
